# 스냅샷 투영 기능 구현 계획

## 📋 개요

측면 이동 후 정면 이미지를 측면에 붙이는 기능 구현 계획서입니다.
- 화살표 버튼으로 면 전환 시 정면 스냅샷을 측면에 투영
- 입체적 투사도 표현
- 원래 면으로 복귀 시 투영 이미지 제거
- 방 크기 변경 시 자동 스케일링

---

## 🎯 핵심 요구사항

1. **측면 이동 후 정면 이미지를 측면에 붙이기**
   - HTML 스냅샷을 방의 직사각형(redRect)만 떠서 4면에 fit
   - UI 버튼은 제외하고 기둥/선반/가구만 캡처

2. **화살표 누르면 스냅샷을 뜨고 이미지를 입체적 투사도 표현**
   - 화살표 버튼 클릭 시 스냅샷 캡처 및 면 전환
   - 측면에 맞게 투시 변환 적용

3. **원래 면으로 이동하면 비어지는 면은 비어질 수 있게**
   - 측면 → 정면 복귀 시 투영 스냅샷 제거
   - 빈 면은 기본 벽 이미지로 표시

4. **방 크기 변경 시 자동 스케일링**
   - 측면 크기가 변경되어도 스냅샷 자동 스케일링
   - 재캡처 없이 기존 스냅샷 유지

### 2. 스냅샷 캡처 유틸리티

#### `src/utils/snapshot.ts` (새로 생성)

**핵심 기능:**
- Canvas의 `redRect` 영역만 추출
- UI 버튼 자동 제외 (Canvas 기반이므로)
- Blob URL로 변환하여 메모리 효율성 확보

**구현 방법:**
```typescript
/**
 * Canvas의 redRect 영역만 캡처하여 Blob URL로 반환
 * @param canvas - 캡처할 Canvas 요소
 * @param redRect - 캡처할 영역 (redRect)
 * @param sourceFaceX - 원본 면의 폭 (mm)
 * @param sourceFaceY - 원본 면의 높이 (mm)
 * @returns Blob URL과 원본 크기 정보
 */
export async function captureFaceSnapshot(
  canvas: HTMLCanvasElement,
  redRect: WallRect,
  sourceFaceX: number,
  sourceFaceY: number
): Promise<{
  imageDataUrl: string;
  sourceFaceX: number;
  sourceFaceY: number;
}> {
  // 1. Canvas에서 redRect 영역만 추출
  const imageData = canvas.getContext('2d')?.getImageData(
    redRect.x,
    redRect.y,
    redRect.width,
    redRect.height
  );
  
  // 2. 새 Canvas에 복사
  const snapshotCanvas = document.createElement('canvas');
  snapshotCanvas.width = redRect.width;
  snapshotCanvas.height = redRect.height;
  const ctx = snapshotCanvas.getContext('2d');
  if (imageData && ctx) {
    ctx.putImageData(imageData, 0, 0);
  }
  
  // 3. Blob으로 변환
  const blob = await new Promise<Blob>((resolve) => {
    snapshotCanvas.toBlob((blob) => {
      resolve(blob || new Blob());
    }, 'image/png');
  });
  
  // 4. Object URL 생성
  const imageDataUrl = URL.createObjectURL(blob);
  
  return {
    imageDataUrl,
    sourceFaceX,
    sourceFaceY,
  };
}
```

**장점:**
- 빠른 성능 (Canvas 직접 추출)
- UI 버튼 자동 제외 (Canvas 레이어 분리)
- 메모리 효율적 (Blob URL 사용)

### 3. 면 전환 로직 수정

#### `src/modules/roomCanvas/store/index.ts`

**`setActiveFaceId` 함수 수정:**

```typescript
/**
 * 활성 면 전환 (스냅샷 캡처 및 투영 처리 포함)
 */
const setActiveFaceId = async (
  faceId: FaceId,
  options?: {
    captureSnapshot?: boolean;  // 스냅샷 캡처 여부
    canvasRef?: Ref<HTMLCanvasElement | null>;  // Canvas 참조
    scaleInfo?: ScaleInfo | null;  // 스케일 정보
  }
) => {
  // 현재 방 형태에서 사용 가능한 면인지 확인
  if (!availableFaces.value.includes(faceId)) {
    console.warn(`Face ${faceId} is not available in shape ${roomState.value.roomShape}`);
    return;
  }

  const currentFaceId = roomState.value.activeFaceId;
  const currentFace = roomState.value.faces[currentFaceId];
  const targetFace = roomState.value.faces[faceId];

  // 정면(1면) → 측면(2,3,4면) 이동 시: 스냅샷 캡처 및 저장
  if (
    currentFaceId === 1 &&
    faceId !== 1 &&
    options?.captureSnapshot &&
    options?.canvasRef?.value &&
    options?.scaleInfo
  ) {
    const { captureFaceSnapshot } = await import('../../../utils/snapshot');
    const snapshot = await captureFaceSnapshot(
      options.canvasRef.value,
      options.scaleInfo.redRect,
      currentFace.face_x,
      currentFace.face_y
    );

    // 측면에 스냅샷 저장
    targetFace.projectedSnapshot = {
      imageDataUrl: snapshot.imageDataUrl,
      sourceFaceId: 1,
      sourceFaceX: snapshot.sourceFaceX,
      sourceFaceY: snapshot.sourceFaceY,
      timestamp: Date.now(),
    };
  }

  // 측면 → 정면(1면) 복귀 시: 투영 스냅샷 제거
  if (currentFaceId !== 1 && faceId === 1) {
    // 이전 측면의 스냅샷 Object URL 해제
    if (currentFace.projectedSnapshot?.imageDataUrl) {
      URL.revokeObjectURL(currentFace.projectedSnapshot.imageDataUrl);
    }
    currentFace.projectedSnapshot = null;
  }

  // 활성 면 변경
  roomState.value.activeFaceId = faceId;
};
```

**동작 흐름:**
1. 정면 → 측면: 스냅샷 캡처 후 측면에 저장
2. 측면 → 정면: 투영 스냅샷 제거 및 메모리 해제
3. 측면 → 다른 측면: 기존 스냅샷 유지 (또는 교체 정책에 따라)

**투영 스냅샷 그리기 함수:**

```typescript
/**
 * 투영된 스냅샷을 측면에 맞게 그리기
 */
function drawProjectedSnapshot(
  ctx: CanvasRenderingContext2D,
  snapshot: {
    imageDataUrl: string;
    sourceFaceId: FaceId;
    sourceFaceX: number;
    sourceFaceY: number;
  },
  currentFaceX: number,
  currentFaceY: number,
  redRect: WallRect
) {
  // 이미지 로드
  const img = new Image();
  img.src = snapshot.imageDataUrl;

  // 이미지 로드 완료 후 그리기
  img.onload = () => {
    // 전체 채우기 방식: redRect 전체를 채우도록 스케일링
    // (현재 벽 이미지와 동일한 방식)
    ctx.save();

    // 측면별 투시 변환 적용
    const activeFaceId = store.activeFaceId.value;
    applyPerspectiveTransform(ctx, activeFaceId, redRect);

    // 스케일링된 크기로 그리기
    ctx.drawImage(
      img,
      redRect.x,
      redRect.y,
      redRect.width,
      redRect.height
    );

    ctx.restore();
  };
}

/**
 * 측면별 투시 변환 적용
 */
function applyPerspectiveTransform(
  ctx: CanvasRenderingContext2D,
  faceId: FaceId,
  redRect: WallRect
) {
  const centerX = redRect.x + redRect.width / 2;
  const centerY = redRect.y + redRect.height / 2;

  ctx.translate(centerX, centerY);

  switch (faceId) {
    case 2: // 왼쪽 측면
      // 왼쪽으로 기울어진 투시
      ctx.transform(0.8, 0, -0.2, 1, 0, 0);
      break;
    case 3: // 오른쪽 측면
      // 오른쪽으로 기울어진 투시
      ctx.transform(0.8, 0, 0.2, 1, 0, 0);
      break;
    case 4: // 뒤쪽 측면
      // 뒤집기 (좌우 반전)
      ctx.scale(-1, 1);
      break;
    default:
      // 정면(1면)은 변환 없음
      break;
  }

  ctx.translate(-centerX, -centerY);
}
```

**주의사항:**
- 이미지 비동기 로딩 처리 필요
- 이미지 캐싱 고려 (한 번 로드한 이미지는 재사용)

### 5. 화살표 버튼 UI 추가

#### `src/components/RoomHeader.vue` 또는 `src/components/RoomCanvas.vue`

**화살표 버튼 추가:**

```vue
<template>
  <!-- 기존 코드 ... -->
  
  <!-- 화살표 버튼 추가 (면 전환용) -->
  <div :style="arrowButtonsContainerStyle">
    <button
      @click="handleFaceRotate('left')"
      :style="arrowButtonStyle"
      :disabled="!canRotateLeft"
    >
      ←
    </button>
    <button
      @click="handleFaceRotate('right')"
      :style="arrowButtonStyle"
      :disabled="!canRotateRight"
    >
      →
    </button>
  </div>
</template>

<script setup lang="ts">
// ... 기존 코드 ...

const handleFaceRotate = async (direction: 'left' | 'right') => {
  const currentFaceId = store.activeFaceId.value;
  const availableFaces = store.availableFaces.value;
  const currentIndex = availableFaces.indexOf(currentFaceId);
  
  let nextFaceId: FaceId;
  if (direction === 'left') {
    // 이전 면
    const prevIndex = currentIndex > 0 ? currentIndex - 1 : availableFaces.length - 1;
    nextFaceId = availableFaces[prevIndex];
  } else {
    // 다음 면
    const nextIndex = currentIndex < availableFaces.length - 1 ? currentIndex + 1 : 0;
    nextFaceId = availableFaces[nextIndex];
  }

  // 스냅샷 캡처 옵션과 함께 면 전환
  await store.setActiveFaceId(nextFaceId, {
    captureSnapshot: true,
    canvasRef: canvasRef,  // RoomCanvas에서 전달
    scaleInfo: scaleInfo.value,
  });
};

const canRotateLeft = computed(() => {
  // 정면(1면)일 때만 왼쪽 회전 가능 (측면으로 이동)
  return store.activeFaceId.value === 1;
});

const canRotateRight = computed(() => {
  // 측면에서 정면으로 복귀 가능
  return store.activeFaceId.value !== 1;
};
</script>
```

### 6. 방 크기 변경 시 자동 스케일링

**이미 구현됨:**
- `drawProjectedSnapshot` 함수에서 `currentFaceX/Y`와 `snapshot.sourceFaceX/Y`를 비교
- `redRect`는 `face_x`, `face_y`에 따라 자동 계산됨
- 따라서 스냅샷도 자동으로 새로운 `redRect` 크기에 맞춰 그려짐

**추가 최적화 (선택사항):**
- 방 크기 변경 감지 시 스냅샷 품질 재확인
- 크기 차이가 너무 크면 경고 표시 (선택사항)

## 🔧 기술적 세부사항

### 스냅샷 캡처 방식
- **방법**: Canvas 직접 추출 (`getImageData`)
- **장점**: 빠른 성능, UI 버튼 자동 제외
- **대상**: `redRect` 영역만 추출

### 투시 변환 방식
- **2면(왼쪽)**: `transform(0.8, 0, -0.2, 1, 0, 0)` - 왼쪽으로 기울임
- **3면(오른쪽)**: `transform(0.8, 0, 0.2, 1, 0, 0)` - 오른쪽으로 기울임
- **4면(뒤쪽)**: `scale(-1, 1)` - 좌우 반전

### 스케일링 방식
- **전체 채우기**: `redRect` 전체를 채우도록 스케일링 (비율 무시)
- **이유**: 현재 벽 이미지와 동일한 방식으로 일관성 유지

### 메모리 관리
- **Blob URL 사용**: `URL.createObjectURL(blob)`
- **해제 시점**: 측면 → 정면 복귀 시 `URL.revokeObjectURL()`
- **주의**: 모든 Object URL이 해제되는지 확인
